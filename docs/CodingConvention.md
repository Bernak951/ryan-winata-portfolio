# 1. Purpose

This document defines the coding standards and implementation conventions
for Portfolio V3.

The purpose is to ensure that the codebase remains:

- Consistent
- Readable
- Maintainable
- Reusable
- Accessible
- Beginner-friendly
- Easy to review
- Easy to extend

These conventions apply to human-written code and AI-assisted code,
including code generated or modified by Kiro AI.

---

# 2. General Principles

The project follows these principles:

1. Prefer simplicity over unnecessary complexity.
2. Reuse existing patterns before creating new patterns.
3. Write readable code before optimizing prematurely.
4. Keep each file focused on a clear responsibility.
5. Avoid unnecessary dependencies.
6. Avoid unnecessary refactoring.
7. Preserve existing functionality when implementing new features.
8. Use semantic HTML whenever possible.
9. Use reusable CSS variables and components.
10. Keep JavaScript modular and focused.
11. Do not introduce a framework unless explicitly approved.
12. Code generated by AI must be reviewed before being committed.

---

# 3. Technology Standards

Portfolio V3 currently uses:

- HTML5
- CSS3
- Vanilla JavaScript
- JSON
- Git
- GitHub

The following should not be introduced without explicit approval:

- React
- Vue
- Angular
- Svelte
- Next.js
- Tailwind CSS
- Bootstrap
- jQuery
- Large UI libraries
- Build frameworks

A new technology may only be introduced when there is a clear
requirement and the architectural impact has been reviewed.
